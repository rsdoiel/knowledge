NAME

kb-link — link projects/observations to concepts

SYNOPSIS

kb link project PROJECT_NAME CONCEPT_NAME

kb link observation OBS_ID CONCEPT_NAME

DESCRIPTION

Links are many-to-many and idempotent — linking the same pair twice is a silent no-op.

SEE ALSO

kb-project(1), kb-observation(1), kb-concept(1)
